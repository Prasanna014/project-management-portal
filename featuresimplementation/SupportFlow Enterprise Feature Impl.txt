SupportFlow Enterprise Feature Implementation Policy

IMPORTANT INSTRUCTION

Before implementing ANY new feature, perform a complete analysis of the existing codebase.

For every requested feature:

1. First inspect the current implementation.
2. Identify whether the feature already exists fully, partially, or not at all.
3. DO NOT immediately generate code changes.
4. Produce an assessment report first.
5. Explain:
   - Existing implementation
   - Existing entities
   - Existing APIs
   - Existing UI pages
   - Existing database tables
   - Existing workflows
   - Current limitations
6. Suggest improvements.
7. Wait for engineering approval before implementing any changes.
8. If the feature already exists and is working correctly, DO NOT duplicate it.
9. If the feature partially exists, explain exactly what should be extended.
10. Only implement after providing analysis and obtaining confirmation.
